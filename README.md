# 🌊 Sea Level Predictor

This project analyzes historical global sea level data and predicts future sea level rise using linear regression.

Built with **Python**, **Pandas**, **Matplotlib**, and **SciPy**, it visualizes trends and provides projections through the year 2050.


## 📊 Features

- Load and analyze real-world sea level data
- Create a scatter plot of historical data
- Generate two regression lines:
  - Based on all available data (1880–present)
  - Based on recent data (from year 2000 onward)
- Predict sea level rise up to 2050
